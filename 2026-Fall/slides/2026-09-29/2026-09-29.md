# Cascading & Positioning


### What does "Cascading" mean?

- You can have multiple rulesets, which can override each other in order
- CSS Rules use "specificity" to determine which rules apply
  - Specificity considers...
    - How "close" to the item the rule is written (external > internal > inline)
    - How detailed the selector is (how many selector and what kinds)
    - The order the rules are read (eg, if you have multiple external stylesheets)
- Some rules are inherited from their parents, like font styles
- There's an "emergency use" `!important `key word... do not use it unless you need to patch mistakes in files you cannot edit!

---

## Multiple files

Rules of CSS files `link`ed later override the rules of previously `link`ed ones.

This is great for...

- Having one stylesheet for "global" styles and one for "this page only" styles
- Having one style sheet per "component"
- Overriding styles you don't have the ability to edit directly (ie, Bootstrap or other imported styles)

# Flexbox

## Laying things out in a row or a column


## The two halves of Flexbox

You need **two** things:

1. A **container** — you set `display: flex` on it
2. Its **children** — they become "flex items" automatically

```css
.card-row {
  display: flex;
}
```

That's it. The children now sit in a row.

---

## flex-direction

Which way do the items go?

```css
.container {
  display: flex;
  flex-direction: row;    /* default - left to right */
  flex-direction: column; /* top to bottom */
}
```

---

## justify-content

Spacing **along** the direction of the row.

```css
.container {
  display: flex;
  justify-content: flex-start;    /* default */
  justify-content: center;
  justify-content: space-between; /* pushed to the edges */
  justify-content: space-around;
}
```

`space-between` is how you make a nav bar with the logo left and links right.

---

## align-items

Spacing **across** the direction of the row.

```css
.container {
  display: flex;
  align-items: stretch;  /* default - same height */
  align-items: center;   /* vertically centered */
  align-items: flex-start;
}
```

**`justify-content: center` + `align-items: center` = perfectly centered.**
This used to be genuinely hard. Now it's two lines.

---

## gap

Space between items, without fighting with margins.

```css
.container {
  display: flex;
  gap: 1rem;
}
```

Use this instead of `margin-right` on every child.

---

## flex-wrap

By default, flex items refuse to wrap and just squish.

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

Almost always what you want. Sets you up for responsive design next week.

---

## A complete nav bar

```css
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
  padding: 1rem;
}
```

# CSS Grid

## Laying things out in rows AND columns


## Flexbox vs Grid

- **Flexbox** — one direction at a time. A row of cards. A nav bar.
- **Grid** — two directions at once. A page layout. A photo gallery.

You'll use both. Flexbox more often.

---

## Making a grid

```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 1rem;
}
```

Three equal columns. `fr` = "fraction of the space available."

---

## Uneven columns

```css
.layout {
  display: grid;
  grid-template-columns: 1fr 3fr;
  gap: 1rem;
}
```

Sidebar (1 part) + main content (3 parts).

---

## The one Grid trick worth memorizing

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 1rem;
}
```

"Fit as many 200px-minimum columns as you can, then stretch them."

This is responsive **with no media queries at all**. We'll talk about why next week.
